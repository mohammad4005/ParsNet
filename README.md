# پارس نت

سامانهٔ اولیهٔ تحت وب برای مدیریت نگهداری و تعمیرات.

## اجرای محلی

در پوشهٔ `maintenance_portal` اجرا کنید:

```powershell
python manage.py runserver
```

سپس `http://127.0.0.1:8000` را باز کنید.

## ورود اولیه

- نام کاربری: `admin`
- گذرواژه: `123`

این حساب مدیر اصلی است. برای محیط عملیاتی، گذرواژه را بلافاصله تغییر دهید.

## ورود به تنظیمات چک‌لیست

برای ساخت حساب مدیریتی دیگر:

```powershell
python manage.py createsuperuser
```

سپس در آدرس `/admin/`، دسته‌های تجهیز، چک‌لیست‌ها و آیتم‌های آن‌ها را مدیریت کنید.
